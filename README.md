# COYA Luxury Website Concept

A responsive React + Vite website concept with a luxury restaurant aesthetic and supplied COYA navigation links.

## Requirements
- Node.js 18+ recommended
- npm

## Run locally
1. Extract this folder.
2. Open the extracted `coya-complete` folder in VS Code.
3. Open Terminal in that folder.
4. Run:

   ```bash
   npm install
   npm run dev
   ```

5. Open the local URL shown by Vite, usually `http://localhost:5173/`.

## Files
- `index.html`: HTML document and font loading
- `package.json`: dependencies and scripts
- `vite.config.js`: Vite React configuration
- `src/main.jsx`: React entry point
- `src/App.jsx`: page content, navigation, menu, cards and demo reservation form
- `src/App.scss`: responsive styling

## Important
This is an unofficial design concept and is not affiliated with COYA. Menu items and prices are illustrative. Reservation form is demo-only and does not submit bookings. External links open supplied COYA pages. Verify imagery, current venue details, permissions and branding before using commercially.
